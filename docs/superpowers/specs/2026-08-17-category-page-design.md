# 商品分类页面设计文档

## 1. 背景与目标

客户需要将虚拟空间商品中的商品分类弹窗升级为一个完整的独立页面，提供更好的浏览体验。

### 现有问题
- 当前分类弹窗宽度最大338px，空间受限
- 右侧仅显示子分类按钮，无法直接浏览商品
- 弹窗形式不利于长时间浏览和筛选

### 设计目标
- 创建完整的分类页面，替代弹窗体验
- 左侧大类导航 + 右侧商品直接展示
- 三列网格布局，类似电商APP风格
- 商品卡片采用上下结构（图片 + 标题）

---

## 2. 页面结构

```
┌─────────────────────────────────────────┐
│  ← 返回    商品分类     🔍 搜索       │  ← 顶部导航栏
├────────┬────────────────────────────────┤
│ 房型类 │  ┌─────┐ ┌─────┐ ┌─────┐     │
│ 装修类 │  │ 图片 │ │ 图片 │ │ 图片 │     │
│ 家具类 │  ├─────┤ ├─────┤ ├─────┤     │
│ 文具   │  │标题 │ │标题 │ │标题 │     │
│ 装饰类 │  └─────┘ └─────┘ └─────┘     │
│ 饰品类 │  ┌─────┐ ┌─────┐ ┌─────┐     │
│ 灯具类 │  │ 图片 │ │ 图片 │ │ 图片 │     │
│ 文案类 │  ├─────┤ ├─────┤ ├─────┤     │
│        │  │标题 │ │标题 │ │标题 │     │
│        │  └─────┘ └─────┘ └─────┘     │
└────────┴────────────────────────────────┘
  100px         剩余宽度（三列网格）
```

### 2.1 顶部导航栏
- **高度**: 56px
- **内容**: 返回按钮 + 页面标题"商品分类" + 搜索框
- **样式**: 白色背景，底部边框

### 2.2 左侧分类栏
- **宽度**: 100px
- **背景**: #f3f4f6（浅灰色）
- **内容**: 8个大类标签，垂直排列
- **交互**: 点击切换，当前选中项高亮（粉色左边框）
- **滚动**: 独立垂直滚动

### 2.3 右侧商品区域
- **宽度**: calc(100% - 100px)
- **布局**: 三列网格（grid）
- **间距**: 8px
- **滚动**: 独立垂直滚动
- **背景**: #f3f4f6

## 3. 商品卡片设计

### 3.1 卡片结构
```
┌─────────────┐
│             │
│    图片     │  ← 正方形，object-fit: cover
│             │
├─────────────┤
│ 商品标题     │  ← 单行显示，溢出省略
└─────────────┘
```

### 3.2 卡片尺寸
- **宽度**: 自适应列宽（约 (100vw - 100px - 16px) / 3）
- **图片高度**: 与宽度相等（正方形）
- **标题区域**: 32px高度
- **卡片总高**: 图片高度 + 32px

### 3.3 卡片样式
- **背景**: #ffffff
- **边框**: 1px solid #e5e7eb
- **图片**: object-fit: cover
- **标题**: 12px字体，单行省略

## 5. 交互逻辑

### 5.1 分类切换
1. 用户点击左侧分类标签
2. 移除所有标签的`active`类
3. 为当前标签添加`active`类
4. 筛选右侧商品列表，仅显示对应分类的商品

### 5.2 商品筛选
```javascript
function filterProducts(category) {
  return products.filter(p => p.category === category)
}
```

### 5.3 搜索功能
1. 用户在搜索框输入关键词
2. 实时筛选商品标题包含关键词的商品
3. 支持分类 + 关键词组合筛选
