# 智慧空间 P5 剩余页面实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐 `预期修改完成效果截图\` 中剩余 26 屏对应的页面（设置组 8 页 + 说明类 3 页 + 业务类 5 页 + 精修 3 页），并完成入口接线，使 48 屏全部可复现。

**Architecture:** 纯静态 HTML，无构建步骤。沿用 P4 建立的约定：`www/assets/vendor/theme.css` 提供设计 token 与公共类；主 Tab 页通过 `postMessage` 控制 `index.html` 的底部导航；子页面自带青色顶栏。设置组 8 页共用同一骨架（本文件「共享骨架」一节给出完整代码），差异仅在行内容。

**Tech Stack:** HTML / 内联 CSS / Tailwind 3（本地 CDN JS）/ iconify-icon（本地）/ Chrome headless 截图验证

## 全局约束（同 P4）

1. 文案照抄 `预期修改完成效果截图\`（含全角符号）。
2. 颜色只用 token：`var(--brand)` `var(--brand-strong)` `var(--brand-deep)` `var(--brand-soft)` `var(--brand-tint)` `var(--brand-line)` `var(--gold)` `var(--ink-900)` `var(--ink-700)` `var(--ink-500)` `var(--ink-100)` `var(--page-bg)`。
3. 顶栏用 `class="topbar"`，主按钮 `class="btn-brand"`，描边按钮 `class="btn-brand-outline"`。
4. 图片路径必须真实存在，新增素材放 `www/assets/v2/`（P4 已建）。
5. 主 Tab 页保留 `postMessage({type:'setBottomNav',visible:true})`；子页面**不发**此消息。
6. 安全区：根容器保留 `padding-top/bottom: var(--safe-area-inset-*)`。
7. 一个 Task 一次 commit，信息用 `feat(p5): ...`。
8. **依赖自检**：页面若使用 `var(--brand-*)` / `var(--ink-*)` 等变量，`<head>` 必须有
   `<link href="assets/vendor/theme.css" rel="stylesheet"/>`；若使用 `<iconify-icon>` 标签，必须有
   `<script src="assets/vendor/iconify-icon.min.js"></script>`。当前缺依赖的页面：
   `category.html`（缺两者）、`group_chat.html`（缺两者）、`room_chat.html`（缺 theme.css）、
   `owner_profile.html`（缺 iconify）、`onboarding_birth.html`（缺 iconify）。
   对应 Task 的 Step 1 已包含补依赖操作。
