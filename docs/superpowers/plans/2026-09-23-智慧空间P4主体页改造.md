# 智慧空间 P4 主体页改造实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 7 个主体页从「颜色已换」推进到与 `预期修改完成效果截图\` 结构一致，覆盖 48 张目标图中的第 9~16、24~30、32~35 屏。

**Architecture:** 纯静态 HTML，无构建步骤。每个页面是独立 `www/*.html`，主 Tab 页由 `www/index.html` 的 `<iframe>` 承载，页面通过 `window.parent.postMessage({type:'setBottomNav',visible:true})` 控制底部导航显隐。样式 = 本地 Tailwind（`assets/vendor/tailwindcss.js`）+ `assets/vendor/theme.css` 设计 token + 每页内联 `<style>`。图标 = 本地 `iconify-icon.min.js`（solar 图标集）或 PNG 素材。

**Tech Stack:** HTML / 内联 CSS / Tailwind 3（CDN JS 本地化）/ iconify-icon（本地）/ Chrome headless 截图验证

---

## 全局约束（每个 Task 都适用）

1. **文案照抄目标图**：`预期修改完成效果截图\` 里的中文逐字照抄（含错别字、全角符号）。
2. **颜色只用 token**：`var(--brand)` `var(--brand-strong)` `var(--brand-deep)` `var(--brand-soft)` `var(--brand-tint)` `var(--brand-line)` `var(--gold)` `var(--ink-900)` `var(--ink-700)` `var(--ink-500)` `var(--ink-100)` `var(--page-bg)`；禁止再出现 `#ec4899` 系粉色。
3. **顶部青色栏**统一用 `class="topbar"`；主按钮用 `class="btn-brand"`；描边按钮 `class="btn-brand-outline"`；选择 chip 用 `class="chip"`。
4. **图片路径必须真实存在**，否则页面出现空白块（本项目最易犯的错误）。新增素材统一放 `www/assets/v2/`。
5. **主 Tab 页**（room_list / profile / radar / publish / profile_settings）必须保留首行脚本：
   ```html
   <script>window.parent.postMessage({ type: 'setBottomNav', visible: true }, '*')</script>
   ```
   子页面（message_center / my_contacts / ai_voice / 设置类）不发此消息，由 index.html 默认隐藏。
6. **安全区**：根容器保留
   `style="padding-top: var(--safe-area-inset-top, env(safe-area-inset-top, 0px)); padding-bottom: var(--safe-area-inset-bottom, env(safe-area-inset-bottom, 0px));"`
7. **提交粒度**：一个 Task 一次 commit，信息用 `feat(p4): ...` 格式。
