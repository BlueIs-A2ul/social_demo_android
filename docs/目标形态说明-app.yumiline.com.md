## 一、产品定位与整体形态

**一句话定位**：以「房间 / 空间」为个人入口的元社交 App，把「虚拟身份（名片 / 简历）→ 即时通讯 → 信息栏（招聘 / 搭子）→ 内容广场 → 雷达发现 → 商城 / VIP」串成一条闭环。

整体形态：

- **虚拟身份体系**：每个用户有个人名片（V 编号）与个人简历（JL 编号），公司有公司名片 / 公司简历，可被他人查看并发起聊天。
- **房间 / 空间**：用户拥有多个「房间」（房间列表 + 访客动态 + 置顶），他人可进入房间查看模块（我的播客 / 直播间 / 信息栏 / 我的收藏）并加好友。
- **IM**：信息中心（会话）+ 通讯录（A–Z + 新的朋友）+ 群聊 + 文字 / 语音消息。
- **信息栏**：招聘与「搭子」信息流，支持详情页与发布。
- **广场（TV Tab）**：商城 / 关注 / 发现 / 同城四个频道 + 个人主页（作品 / 草稿 / 私密 / 收藏 / 点赞）。
- **雷达**：附近的人、距离筛选、附近推荐、加好友。
- **商业化**：商城（分类 / 商品 / 订单）、VIP1–VIP7、币种（官方币 / RMB / 积分）。
- **视觉基调**：青色主题 + 金色点缀（见第八节设计 token）。

## 五、模块功能明细

### 5.1 引导问卷（可跳过）

- 每屏固定结构：顶部返回 + 「跳过」；大标题两行（「告诉我们 / 你的 XX」或「选择 / 你的 XX」）；选择区；底部主按钮「下一步」。
- 性别：男 / 女 / 其它。
- 出生年份、出生月日：页面内数字键盘（`1~9 0 #` + 删除键），输入回显。
- 文化偏好 / 兴趣特长 / 互动方式：标签分组多选（具体标签见原型抓取记录，实现时逐字照抄）。

### 5.2 房间 / 空间

- 房间列表顶部：用户昵称 + 「N个空间」+ 消息红点；搜索框 + 圆形新建按钮。
