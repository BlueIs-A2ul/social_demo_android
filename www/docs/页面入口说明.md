# 页面入口说明

本目录共 29 个页面，均已验证可以从 `login.html` 出发一路点击到达，无需单独打开。每个页面也可以直接双击单独查看。

整体起点：双击打开 `login.html`，点击"本机号码一键登录"进入 `index.html`（App 首页外壳），所有页面都从首页底部 5 个 Tab 及页面内点击展开。

---

## 一、一级页面（index 底部 5 个 Tab）

| 页面 | 入口 |
| --- | --- |
| index.html | 起点。login.html 一键登录；onboarding_interests.html 新手指引完成后自动进入 |
| radar.html | index 底部"雷达"Tab（默认页） |
| room_list.html | index 底部"房间"Tab |
| profile.html | index 底部"空间"Tab |
| publish.html | index 底部"分享"Tab |
| announcements.html | index 底部"公告"Tab |

## 二、新用户引导（共三步）

| 页面 | 入口 |
| --- | --- |
| onboarding_gender.html | login.html 点"进入新手指引" |
| onboarding_birth.html | onboarding_gender.html 点"下一步" |
| onboarding_interests.html | onboarding_birth.html 点"下一步"，完成后自动进入 index |
